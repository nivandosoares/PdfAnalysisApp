# PDF Analysis App

Painel ASP.NET Core para gerenciamento de PDFs e solicitações.

**Arquivos principais**

- [PdfAnalysisApp.csproj](<PdfAnalysisApp.csproj>)
- [Controllers/PdfController.cs](<Controllers/PdfController.cs>)
- [Controllers/RequestController.cs](<Controllers/RequestController.cs>)

## Desenvolvimento local

O projeto usa .NET 8. A partir da raiz, execute:

```sh
dotnet restore
dotnet run --project PdfAnalysisApp.csproj
```
